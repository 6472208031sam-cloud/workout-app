# Workout — hosted version

A shareable, single-file web version of the Workout app for use on other people's devices.

Open it here: https://6472208031sam-cloud.github.io/workout-app/

Two plans:
- **Core & Posture** — core/abs and posture sessions on chosen training days
- **Beyond the Rim** — the 20-week jump program by Nathanael Morton (Bodyweight Edition), with the book's demonstration video links

Each visitor's plan, check-offs and progress are saved in their own browser on their own device (localStorage). Nothing syncs between devices, and there are no reminders or calendar features in this version.
